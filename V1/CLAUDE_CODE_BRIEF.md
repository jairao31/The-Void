## 1. PRODUCT OVERVIEW

### What is this app?

A mobile app that does nothing — deliberately. Users set a timer, the screen goes blank, and they sit in silence. Afterwards they log whatever their idle mind produced. Over time the app tracks their "stillness score" — how long they can sit in stillness — and builds a personal archive of their idle thoughts.

### The core philosophy

- The app works 100% offline, forever
- No account required to use the app
- Thoughts are private and stored locally — never sent to any server in readable form
- The app does not nag, guilt, or streak-shame the user
- Every screen should feel like a relief to open — minimal, quiet, calm

### What this app is NOT

- Not a meditation app (no guidance, no breathing exercises, no music)
- Not a productivity app (no tasks, no goals)
- Not a social app (no sharing within the app, no profiles)
- Not a journaling app (no long-form writing — max one sentence per session)

## 5. SCORE CALCULATION ALGORITHM

The stillness score is the only number that matters in the app. It must feel meaningful and motivating — not arbitrary.

### Algorithm

```dart
// Called after every completed or partial session
int calculateNewScore({
  required int currentScore,
  required int actualDurationSeconds,
  required int targetDurationSeconds,
  required bool wasCompleted,
  required bool quietModeEnabled,
}) {
  // Base points — scaled to duration
  double basePoints = actualDurationSeconds / 60.0 * 2.0; // 2pts per minute
  
  // Completion bonus
  double completionMultiplier = wasCompleted ? 1.5 : 1.0;
  
  // Quiet mode bonus — small reward for enabling focus
  double quietBonus = quietModeEnabled ? 1.0 : 0.0;
  
  // Consistency bonus — handled separately via streak check
  
  double earned = (basePoints * completionMultiplier) + quietBonus;
  
  // Score cannot decrease — only goes up
  // Cap daily gain at 20 points to prevent gaming
  double dailyGainCap = 20.0;
  double cappedEarned = earned.clamp(0.0, dailyGainCap);
  
  return (currentScore + cappedEarned).round();
}
```

### Score milestones
| Score | Label |
|---|---|
| 0–10 | Just starting |
| 11–25 | Finding stillness |
| 26–50 | Getting quieter |
| 51–100 | Comfortable with silence |
| 101–200 | Deep stillness |
| 200+ | The still mind |

## 6. THOUGHT AUTO-TAGGING

After the user logs a thought, the app auto-tags it. This runs locally — no API call.

```dart
// Simple keyword-based tagger — runs in isolate, no network
String? autoTag(String thought) {
  final lower = thought.toLowerCase();
  
  // People signals
  if (lower.contains(RegExp(r'\b(mum|dad|friend|call|family|someone|they|her|him|people|talk)\b'))) {
    return 'people';
  }
  
  // Idea signals
  if (lower.contains(RegExp(r'\b(idea|build|make|could|should|project|app|what if|maybe)\b'))) {
    return 'idea';
  }
  
  // Memory signals
  if (lower.contains(RegExp(r'\b(remember|used to|when i|back when|years ago|childhood|once)\b'))) {
    return 'memory';
  }
  
  // Question signals
  if (lower.contains(RegExp(r'\b(why|how|what|wonder|curious|question)\b'))) {
    return 'question';
  }
  
  return null; // untagged
}
```

## 9. BACKUP & RESTORE IMPLEMENTATION

### Backup flow (full code outline)

```dart
class BackupService {
  
  Future<void> performBackup({
    required String backupPassword,
    required AppDatabase db,
    required FirebaseStorage storage,
    required FirebaseAuth auth,
  }) async {
    // 1. Export all data from drift as JSON
    final exportData = await db.exportToJson();
    final jsonString = jsonEncode(exportData);
    final jsonBytes = utf8.encode(jsonString);
    
    // 2. Derive encryption key from password
    final key = _deriveKey(backupPassword);
    
    // 3. Encrypt with AES-256
    final iv = IV.fromSecureRandom(16);
    final encrypter = Encrypter(AES(key, mode: AESMode.cbc));
    final encrypted = encrypter.encryptBytes(jsonBytes, iv: iv);
    
    // 4. Prepend IV to encrypted bytes
    final outputBytes = Uint8List.fromList([...iv.bytes, ...encrypted.bytes]);
    
    // 5. Upload to Firebase Storage
    final userId = auth.currentUser!.uid;
    final ref = storage.ref('backups/$userId/backup.enc');
    await ref.putData(outputBytes);
    
    // 6. Save backup metadata locally
    await _saveBackupMetadata(DateTime.now());
  }
  
  Future<void> performRestore({
    required String backupPassword,
    required AppDatabase db,
    required FirebaseStorage storage,
    required FirebaseAuth auth,
  }) async {
    // 1. Download encrypted blob
    final userId = auth.currentUser!.uid;
    final ref = storage.ref('backups/$userId/backup.enc');
    final encryptedBytes = await ref.getData();
    
    // 2. Extract IV (first 16 bytes)
    final iv = IV(Uint8List.fromList(encryptedBytes!.sublist(0, 16)));
    final encryptedData = Encrypted(
      Uint8List.fromList(encryptedBytes.sublist(16))
    );
    
    // 3. Derive key and decrypt
    final key = _deriveKey(backupPassword);
    final encrypter = Encrypter(AES(key, mode: AESMode.cbc));
    final decryptedBytes = encrypter.decryptBytes(encryptedData, iv: iv);
    
    // 4. Decode JSON
    final jsonString = utf8.decode(decryptedBytes);
    final exportData = jsonDecode(jsonString);
    
    // 5. Import into drift database
    await db.importFromJson(exportData);
  }
  
  Key _deriveKey(String password) {
    final passwordBytes = utf8.encode(password);
    final salt = utf8.encode('the_void_salt_v1'); // fixed salt is fine for this use case
    final pbkdf2 = Hmac(sha256, passwordBytes);
    // 10,000 iterations
    var key = salt;
    for (int i = 0; i < 10000; i++) {
      key = pbkdf2.convert(key).bytes;
    }
    return Key(Uint8List.fromList(key.sublist(0, 32)));
  }
}
```

## 17. EDGE CASES TO HANDLE

| Scenario | Handling |
|---|---|
| App backgrounded mid-session | Session timer continues via isolate/background task. On foreground return, show current elapsed time. |
| Phone call received during session | OS handles. If quiet mode was enabled by user, call is silenced (OS default). App does nothing special. |
| App killed mid-session | On next launch, check if there's an incomplete session in DB. If so, show: `"Looks like your last session was interrupted. Want to log it?"` |
| User changes system time | Use monotonic clock (Stopwatch) not wall clock for session timing. |
| Backup password forgotten | Cannot recover. Show clear warning. Offer: `"Start fresh backup with new password"` — overwrites old backup. |
| No internet for backup | Show: `"No connection. Your thoughts are safe on your phone."` Retry silently when connection returns. |
| Restore on device with existing data | Show: `"This will replace all current data on this device. Are you sure?"` Two-step confirmation. |
| First session (no score yet) | Score displays as `0`. Progress bar empty. No "vs last week" comparison shown. |
| Thought input is empty on save | Treat as skip — save session without thought. Don't show validation error. |
| User tries to back during countdown | No back allowed. Countdown is 3 seconds — not worth interrupting. |
| Notification permission denied | App works fine without it. Settings shows toggle grayed out with note: `"Enable in phone settings"`. |
| Drift migration (future schema changes) | Version 1 only for MVP. Document migration strategy in a TODO comment in `app_database.dart`. |
