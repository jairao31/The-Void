## DATABASE SCHEMA — COMPLETE

### Overview
All data lives in a single SQLite file at:
`{app_documents_directory}/the_void.sqlite`

Managed by drift ORM. Schema version: 1.

### Table: sessions

Stores every void session the user starts, including incomplete ones.

| Column | Type | Constraints | Description |
|---|---|---|---|
| id | INTEGER | PRIMARY KEY, AUTOINCREMENT | Internal row ID |
| uuid | TEXT | NOT NULL, UNIQUE, LENGTH(36) | UUID v4 — external identifier |
| started_at | DATETIME | NOT NULL | When session began |
| ended_at | DATETIME | NULLABLE | When session ended (null if still active) |
| target_duration_seconds | INTEGER | NOT NULL | What user aimed for |
| actual_duration_seconds | INTEGER | NOT NULL, DEFAULT 0 | How long they actually lasted |
| was_completed | BOOLEAN | NOT NULL, DEFAULT false | Did they reach the target? |
| quiet_mode_enabled | BOOLEAN | NOT NULL, DEFAULT false | Did they enable Focus/DND? |
| was_interrupted | BOOLEAN | NOT NULL, DEFAULT false | Did they end early manually? |
| interrupt_reason | TEXT | NULLABLE | What they logged as the reason for ending early |
| points_earned | INTEGER | NOT NULL, DEFAULT 0 | Stillness points from this session |

**Indexes:**
- `idx_sessions_started_at` on `started_at DESC` — for date-range queries
- `idx_sessions_uuid` on `uuid` — for backup/restore lookups

### Table: thoughts

Stores idle thoughts logged after sessions.

| Column | Type | Constraints | Description |
|---|---|---|---|
| id | INTEGER | PRIMARY KEY, AUTOINCREMENT | Internal row ID |
| uuid | TEXT | NOT NULL, UNIQUE, LENGTH(36) | UUID v4 — external identifier |
| session_id | INTEGER | NOT NULL, FK → sessions.id | The session this thought came from |
| content | TEXT | NOT NULL, MAX LENGTH 500 | The thought text |
| tag | TEXT | NULLABLE | Auto-tag: 'idea' / 'people' / 'memory' / 'question' |
| created_at | DATETIME | NOT NULL | When the thought was logged |

**Indexes:**
- `idx_thoughts_session_id` on `session_id`
- `idx_thoughts_created_at` on `created_at DESC`
- `idx_thoughts_tag` on `tag` — for filter queries
- Full-text search via drift's `LIKE` query on `content`

### Table: daily_scores

Stores one row per day — a snapshot of the user's cumulative score.

| Column | Type | Constraints | Description |
|---|---|---|---|
| id | INTEGER | PRIMARY KEY, AUTOINCREMENT | Internal row ID |
| date | TEXT | NOT NULL, UNIQUE, FORMAT 'YYYY-MM-DD' | The calendar date |
| score | INTEGER | NOT NULL | Cumulative score at end of this day |
| sessions_today | INTEGER | NOT NULL, DEFAULT 0 | How many sessions on this day |
| minutes_today | INTEGER | NOT NULL, DEFAULT 0 | Total minutes in void on this day |
| longest_session_today | INTEGER | NOT NULL, DEFAULT 0 | Longest session in seconds |
| points_earned_today | INTEGER | NOT NULL, DEFAULT 0 | Points earned on this day |

**Indexes:**
- `idx_daily_scores_date` on `date DESC`

### Table: milestones

Tracks which milestones have been unlocked and when.

| Column | Type | Constraints | Description |
|---|---|---|---|
| id | INTEGER | PRIMARY KEY, AUTOINCREMENT | Internal row ID |
| milestone_key | TEXT | NOT NULL, UNIQUE | Identifier string (see list below) |
| unlocked_at | DATETIME | NOT NULL | When it was first unlocked |

**Milestone keys (complete list):**

| Key | Unlock condition |
|---|---|
| `first_2_min` | Complete any session ≥ 2 minutes |
| `first_5_min` | Complete any session ≥ 5 minutes |
| `first_10_min` | Complete any session ≥ 10 minutes |
| `first_20_min` | Complete any session ≥ 20 minutes |
| `seven_day_streak` | Sessions on 7 consecutive calendar days |
| `ten_sessions` | Complete 10 total sessions |
| `fifty_sessions` | Complete 50 total sessions |
| `first_thought` | Log any thought after any session |
| `ten_thoughts` | Log 10 total thoughts |
| `quiet_mode_five` | Enable quiet mode in 5 sessions |

## SCORE CALCULATION ALGORITHM

```dart
// Called after every session ends (completed or interrupted)
int calculatePointsEarned({
  required int actualDurationSeconds,
  required int targetDurationSeconds,
  required bool wasCompleted,
  required bool quietModeEnabled,
}) {
  // Base: 2 points per minute of actual time in void
  double basePoints = (actualDurationSeconds / 60.0) * 2.0;

  // Completion bonus: 1.5x multiplier if they hit the target
  double completionMultiplier = wasCompleted ? 1.5 : 1.0;

  // Quiet mode bonus: +1 flat point for enabling focus
  double quietBonus = quietModeEnabled ? 1.0 : 0.0;

  double earned = (basePoints * completionMultiplier) + quietBonus;

  // Daily cap: max 20 points per day to prevent gaming
  // Check today's total before adding — if already at 20, return 0
  return earned.round().clamp(0, 20);
}

// New score = previous score + points earned (never subtract)
int newScore = currentScore + pointsEarned;
```

### Score label thresholds

| Score range | Label shown in UI |
|---|---|
| 0–10 | Just starting |
| 11–25 | Finding stillness |
| 26–50 | Getting quieter |
| 51–100 | Comfortable with silence |
| 101–200 | Deep stillness |
| 200+ | The still mind |

## THOUGHT AUTO-TAGGING ALGORITHM

Runs locally in an isolate immediately after the user saves a thought. No network call.

```dart
String? autoTag(String thought) {
  final lower = thought.toLowerCase();

  if (lower.contains(RegExp(
    r'\b(mum|dad|mum|mom|friend|family|call|someone|they|her|him|people|talk|miss|relationship|person)\b'
  ))) return 'people';

  if (lower.contains(RegExp(
    r'\b(idea|build|make|could|should|project|app|what if|maybe|start|create|design|solution|invent)\b'
  ))) return 'idea';

  if (lower.contains(RegExp(
    r'\b(remember|used to|when i|back when|years ago|childhood|once|always|never|before|past|old)\b'
  ))) return 'memory';

  if (lower.contains(RegExp(
    r'\b(why|how|what|wonder|curious|question|does|is it|are we|should i|could it)\b'
  ))) return 'question';

  return null; // untagged — shown in "All" but no specific filter
}
```

## ENCRYPTION IMPLEMENTATION

### Key derivation

```dart
Key deriveKey(String password) {
  final passwordBytes = utf8.encode(password);
  final salt = utf8.encode('the_void_salt_v1');
  final pbkdf2 = Hmac(sha256, passwordBytes);
  var key = salt;
  for (int i = 0; i < 10000; i++) {
    key = pbkdf2.convert(key).bytes;
  }
  return Key(Uint8List.fromList(key.sublist(0, 32)));
}
```

### Encrypt (before upload)

```dart
Uint8List encryptBackup(String jsonString, String password) {
  final key = deriveKey(password);
  final iv = IV.fromSecureRandom(16);
  final encrypter = Encrypter(AES(key, mode: AESMode.cbc));
  final encrypted = encrypter.encrypt(jsonString, iv: iv);
  // Prepend IV to encrypted bytes so decrypt can extract it
  return Uint8List.fromList([...iv.bytes, ...encrypted.bytes]);
}
```

### Decrypt (after download)

```dart
String decryptBackup(Uint8List encryptedBytes, String password) {
  final key = deriveKey(password);
  final iv = IV(Uint8List.fromList(encryptedBytes.sublist(0, 16)));
  final data = Encrypted(Uint8List.fromList(encryptedBytes.sublist(16)));
  final encrypter = Encrypter(AES(key, mode: AESMode.cbc));
  return encrypter.decrypt(data, iv: iv);
}
```

## NOTIFICATION SCHEDULING

### Daily "Now." notification

```dart
// Scheduled once per day at midnight, fires at random time between 8am–9pm
void scheduleNowNotification() async {
  final random = Random();
  final hour = 8 + random.nextInt(13);   // 8–20
  final minute = random.nextInt(60);

  final tz.TZDateTime scheduledTime = tz.TZDateTime(
    tz.local,
    DateTime.now().year,
    DateTime.now().month,
    DateTime.now().day,
    hour,
    minute,
  );

  await flutterLocalNotificationsPlugin.zonedSchedule(
    1, // notification ID
    '', // title — intentionally empty
    'Now.',
    scheduledTime,
    const NotificationDetails(
      iOS: DarwinNotificationDetails(presentAlert: true, presentSound: false),
      android: AndroidNotificationDetails(
        'the_void_now',
        'Now.',
        channelDescription: 'Daily stillness nudge',
        importance: Importance.low,
        priority: Priority.low,
        playSound: false,
      ),
    ),
    androidScheduleMode: AndroidScheduleMode.exactAllowWhileIdle,
    uiLocalNotificationDateInterpretation:
      UILocalNotificationDateInterpretation.absoluteTime,
  );
}
```
