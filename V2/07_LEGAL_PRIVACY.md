## PRIVACY POLICY

### What data The Void collects

**V1 — Collected**
| Data | What it is | Where stored | Who can read it |
|---|---|---|---|
| Anonymous UUID | Random device identifier, generated locally | Device (flutter_secure_storage) | Nobody — never leaves device unencrypted |
| Email address | Only if user signs up for backup | Firebase Auth servers | Firebase (per their policy) + us |
| Firebase UID | Auto-generated by Firebase on sign-up | Firebase Auth servers | Firebase + us |
| Encrypted backup blob | Entire local database, AES-256 encrypted | Firebase Storage | Nobody — only decryptable with user's own password |
| Install date | Local ISO date string | Device (SharedPreferences) | Nobody — never leaves device |
| Theme preference | 'light'/'dark'/'system' | Device (SharedPreferences) | Nobody — never leaves device |
| Notification settings | On/off preferences | Device (SharedPreferences) | Nobody — never leaves device |

**V1 — NOT collected**
- Thought content (stays on device, only leaves encrypted)
- Session content or duration (stays on device)
- Location data
- Device model or OS version
- IP address
- Any behavioural analytics
- Crash reports
- Payment data (V1 has no payments)

**V2 additions (with user consent)**
- Anonymous usage events via PostHog (opted-in only, no PII)
- Subscription status via RevenueCat (for payment processing)
- Payment data via Apple/Google (handled entirely by App Store — we never see card details)

### How data is used
- Email / Firebase UID: only to authenticate the user for backup access
- Encrypted backup: only to restore the user's own data on request
- Nothing is sold. Nothing is shared with advertisers. Nothing is used to train AI.

### How long data is kept
- Email / Firebase UID: until user deletes their account
- Encrypted backup: until user deletes their account or overwrites with new backup
- On delete account: all Firebase Auth + Storage data purged within 30 days
- Local device data: purged immediately on "Delete all my data"

### Privacy policy URL
Must be live at: `https://thevoidapp.com/privacy`
Required by: Apple App Store, Google Play, GDPR, CCPA

### Privacy policy must include
1. What data is collected
2. How it is used
3. How long it is kept
4. Who it is shared with (Firebase only, under their DPA)
5. User rights (access, deletion, portability)
6. Contact email for privacy requests: privacy@thevoidapp.com
7. Last updated date
8. Links to Firebase's privacy policy

### Plain-language privacy promise (shown in onboarding)
"Your thoughts are stored on your device. We never read them, sell them, or use them to train anything. Ever."

This promise must be honoured technically (it already is — client-side encryption) and legally (privacy policy must match).

## GDPR COMPLIANCE (EU USERS)

GDPR applies to any app used by EU residents, regardless of where the company is based.

### Legal basis for processing

| Data | Legal basis | Justification |
|---|---|---|
| Email / Firebase UID | Contractual necessity | Required to provide the backup service the user requested |
| Encrypted backup | Contractual necessity | The backup service the user explicitly requested |
| Anonymous analytics (V2) | Consent | Explicit opt-in in Settings |

### User rights — all must be technically implemented

**Right to access**
Users can request all data we hold about them.
What to provide: email address, Firebase UID, last backup timestamp.
Note: we cannot provide thought/session content because we cannot decrypt the backup.
Response time: 30 days.
Contact: privacy@thevoidapp.com

**Right to deletion**
Users can delete all their data at any time.
Already implemented in product: Settings → Delete all my data.
What gets deleted: Firebase Auth account, Firebase Storage backup, local SQLite database.
Timeline: immediate for local data, within 30 days for Firebase data.

**Right to data portability**
Users can request their data in a portable format.
For V1: the backup.enc file is available for download (user must decrypt it themselves with their password).
V2: implement an "Export my data" option that provides decrypted JSON of all their sessions and thoughts.

**Right to object to processing**
Users can turn off analytics at any time (V2 only — V1 has none).

### Data breach protocol
If Firebase experiences a breach affecting our users:
1. Assess scope within 24 hours
2. Notify relevant supervisory authority within 72 hours (required by GDPR)
3. Notify affected users without undue delay
4. Document the breach and our response
5. Note: encrypted backup contents are unreadable even in a breach — a strong mitigation

### Data Processing Agreement (DPA)
Firebase / Google offers a DPA. Sign it before V2 launch.
Available at: https://firebase.google.com/terms/data-processing-terms

## AGE RESTRICTIONS & COPPA

### Target age
The Void is designed for adults (18+). The content is philosophical and adult in nature — themes of mortality, silence, and self-reflection.

### Age gate
No explicit age gate in V1. The App Store age rating of 4+ is the technical gate.
The product is not designed for or marketed to children.

### COPPA (US — under 13)
COPPA applies if an app knowingly collects data from children under 13.
The Void's mitigation:
- No account required (V1 collects nothing without sign-up)
- Sign-up requires email — children under 13 typically don't have independent email accounts
- App Store / Play Store parental controls provide additional filtering
- Privacy policy explicitly states: "The Void is not directed at children under 13. If you are under 13, please do not use this app."

### If a child under 13 is identified as a user
Delete their account and associated data immediately upon discovery.
Contact: privacy@thevoidapp.com

## DATA RETENTION & DELETION POLICY

### Active users
- All data kept until user deletes it or deletes their account

### After account deletion
| Data type | Retention after deletion | Action |
|---|---|---|
| Firebase Auth account | Deleted within 24 hours | Firebase handles |
| Firebase Storage backup | Deleted within 30 days | Storage rules allow deletion via Security Rules + our delete call |
| Local SQLite database | Deleted immediately | Handled by "Delete all my data" function |
| Email address in Firebase | Deleted with auth account | Firebase handles |
| Anonymous UUID | Deleted from device | Handled by app |
| PostHog events (V2) | Anonymised within 90 days | PostHog data retention settings |

### Inactive accounts
After 2 years of no sign-in: send deletion warning email → 30-day notice → delete account and backup.
This is a V2 concern — implement when user base justifies it.

### Legal hold exception
If required by law (e.g. court order), we may be required to retain certain data beyond these timelines. This would be disclosed in the privacy policy update at that time.
